# M1 蓝海战略草案：ERRC 与新商业模式画布

> 日期：2026-11-12；状态：讨论稿，非团队冻结的MVP。收入/成本模块待M4专门材料。

## 1. 战略问题

市场并不缺少收藏、批注、讨论或知识关联能力。候选问题是：用户是否需要把跨来源片段、出处/定位和自己的想法作为一个可携带的记录单元，并低摩擦地回到原内容、检索和分享。现有工具组合是否造成足够频繁且严重的损失，尚待验证。

## 2. ERRC

| 行动 | M1提议 | 依据与边界 |
|---|---|---|
| 删除 | 自建播放器、音频托管、内容分发、泛关注流、粉丝数竞争 | 不与小宇宙/喜马拉雅争夺内容消费；聚焦内容后的思考 |
| 消减 | 强制分类/长笔记、强制手工填写出处、默认AI摘要/转录、开放式公共社区运营 | 低频用户对复杂操作有阻力；AI能力已被竞品覆盖且成本未知。出处可自动带入则带入，不能取得时允许跳过 |
| 提升 | 捕捉入口轻量、片段与来源定位绑定、个人想法可选、原平台回跳、开放导出和隐私控制 | 用户访谈与竞品比较支持作为候选差异，但不能声称这些能力完全不存在 |
| 创造 | 跨来源观点卡：片段/摘录 + 出处/时间点/页码 + 可选个人想法 + 原内容回跳 + 分享链接/卡片 | 组合价值假设，非已证实市场空白；需原型对照测试。讨论为可选分支 |

## 4. 新BMC（暂定）

| 模块 | 候选内容 | 状态 |
|---|---|---|
| 客户细分 | 高频消费播客/书籍/长文章，且最近真实做过收藏、截图、批注、分享或回找的人 | 假设，待细分验证 |
| 价值主张 | 跨来源观点卡：片段、出处定位、可选个人想法，支持检索、回原内容和分享 | 假设，须证明优于现有工具组合 |
| 渠道通路 | Web/PWA、系统分享入口、浏览器扩展、链接导入；尽量不要求接收者安装 | 假设，平台API待技术验证 |
| 客户关系 | 默认私密，用户选择分享范围；先使用熟人现有渠道；小规模讨论为后续实验 | 候选 |
| 收入来源 | 暂不冻结；可探索免费基础记录与付费高级检索/同步/团队共读 | 等M4与真实付费验证 |
| 核心资源 | 来源解析与锚点策略、回跳链接维护、个人数据安全/导出、轻量客户端 | 候选 |
| 关键业务 | 捕捉解析、观点卡保存、搜索回跳、分享导出；讨论治理/AI处理后置 | 候选 |
| 重要合作 | 浏览器/系统分享接口、内容平台公开链接/RSS/元数据、云存储/搜索、支付渠道 | 未建立合作关系 |
| 成本结构 | 研发、云存储/搜索、解析与链接稳定性、客服与隐私合规；讨论增加审核成本，AI增加推理成本 | 只有成本类别，无金额 |

## 5. 原型优先级与失败条件

**P0验证任务：**保存来源链接/时间点/页码或手工摘录；自动带入可获得的元数据；可选一句话批注；检索回找；生成可分享卡片/链接，接收者无需注册即可理解上下文。

**暂缓：**公共广场、陌生人匹配、自动知识图谱、强制标签、长笔记、自研播放器、AI转录/摘要、收费价格冻结。

| 风险 | 失败信号 |
|---|---|
| 现有工具已足够 | 用户用原平台收藏+微信/备忘录完成任务且不觉得麻烦 |
| 回跳不可靠 | 时间点/段落链接失效，平台不开放接口 |
| 观点卡增加操作 | 需要大量手工补元数据或写批注才有价值 |
| 跨源关联无真实任务 | 用户不回顾、不搜索、不关联 |
| 讨论需求不足 | 用户只愿分享到熟人群，不愿新社区 |
| 付费不成立 | 用户认可免费但不愿为候选权益付费 |
