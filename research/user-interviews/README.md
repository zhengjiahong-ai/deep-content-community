# 真实用户访谈记录目录

本目录存放去标识化的真实同学访谈摘要和记录。

## 命名建议

- `U01-interview.md`
- `U02-interview.md`
- …
- `U08-interview.md`

文件名只使用匿名编号，不写真实姓名、学号、联系方式或其他可识别信息。

## 记录要求

- 每位组员约完成 2 份访谈；
- 访谈约 10—15 分钟；
- 使用 `docs/RESEARCH_LOG_TEMPLATE.md`；
- 只记录必要的用户背景、具体行为、困难、替代方案和反例；
- 不经明确同意不录音；即使录音也不要把可识别音频上传到公开仓库；
- 不要把研究者推断写成受访者原话。

本目录内容属于真实访谈材料。AI 模拟不得放在这里。
