## 2. 目标用户与任务

- **主要用户**：中文阅读者、研究者、需要长期积累资料的人；官方强调“阅读资产”“终身成长”（E-314）。
- **谁提供内容**：用户自己收藏（微信、网页、App、浏览器扩展、分享菜单、Email、API）。
- **谁可能付费**：收藏量超过 200 篇或需要 AI/快照/同步的个人（Pro 98 元/年、Pro+AI 198 元/年，E-315）。
- **用户为什么打开它**：把散在微信/网页/App 的文章收进一处，读得干净、标得下来、以后找得到（E-314）。
- **解决的是哪类问题**：收藏 + 阅读 + 标注 + 检索/回顾；不是讨论。

## 3. 核心价值主张

- **官方承诺**：一站式收藏、沉浸阅读、多彩高亮与笔记、全文/语义搜索、回顾提醒、同步到 Obsidian/Notion/FlowUs，数据可导出（E-314）。
- **差异化机制**：
  - 微信助手一键转发收藏（中文场景的关键入口）；
  - 网页快照与正文解析，缓解链接失效；
  - 默认私密、无社交推荐与算法推送（官方明确）；
  - 开放 API/CLI，可接入自动化工作流。
- **代价**：免费版 200 篇、每篇 3 个标注；AI 能力按积分（Pro+AI 每月 2000 积分）（E-315）。

## 6. 优势、局限与启示

### 已做得好的能力

1. **中文场景入口最顺**：微信助手一键转发，直接命中“文章在微信里”的现实（E-314）。
2. **来源保全**：正文解析 + 网页快照，链接失效也能读（E-314）。
3. **检索层次完整**：全文、语义、自然语言问答（E-314）。
4. **数据开放**：同步 + API + CLI + 可导出，降低锁定顾虑（E-314、E-315）。
5. **隐私定位清晰**：默认私密、无社交推荐，吸引不愿公开的人（E-314）。

### 能力边界（对本项目最重要）

1. **不做讨论**：官方把“无社交推荐、默认私密”当作卖点，分享是“发出去”，不是“在里面讨论”（E-314）。这正好留下“围绕片段的小范围共读”这一空位，但也说明用户可能并不想在新工具里社交。
2. **内容类型偏图文**：播客/音频不是主线（官方功能表未列音频转录），与本项目“播客 + 书 + 文章”的统一出处有差距（[INFERENCE]，需确认）。
3. **标注与原文的绑定是“网页级”**：能否精确到段落/句子并稳定跳回，需实测（C-4）。
4. **免费额度低**：200 篇/3 标注，重度用户很快付费（E-315）。
5. **AI 积分制**：2000 积分/月，重度使用会受限（E-315）。

### 对本项目的启示

- “收藏 + 标注 + 回顾”在中文环境已被做得相当完整，本项目不能把它当作差异点。
- Cubox 的“默认私密”是一个重要反证：用户未必愿意把阅读与思考公开。本项目若做讨论，必须限定在“熟人/小范围”，且不能要求对方安装（与 `PHASE1_FINDINGS` 的 P2 任务一致）。
- Cubox 的“快照”思路值得借用：出处不仅是链接，还应有一份可回溯的副本，否则链接失效后“来源上下文”就是空的。
