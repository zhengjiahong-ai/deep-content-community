## 2. 目标用户与任务

Cubox 的用户是中文阅读者，尤其是那种每天在微信、网页、App 里存了一堆文章的人。官方爱讲“阅读资产”“终身成长”，说白了就是让你存下来的东西别吃灰（E-314）。

内容全是用户自己收藏进来的：微信、网页、App、浏览器扩展、分享菜单、Email、API。Cubox 不产内容，它负责收、排版、标注、以后能找回来。

愿意付费的是收藏超过 200 篇，或者需要 AI、快照、同步的人。Pro 98 元一年，Pro+AI 198 元一年（E-315）。打开它的理由很实在：把散在微信和网页里的文章收进一处，读得干净，标得下来，以后找得到（E-314）。讨论不在它的范围内。

## 3. 核心价值主张

官方承诺是一站式收藏、沉浸阅读、多彩高亮和笔记、全文/语义搜索、回顾提醒，还能同步到 Obsidian/Notion/FlowUs，数据可以导出（E-314）。

它跟同类比，差异在四个地方：微信助手一键转发，直接命中“文章在微信里”的现实；网页快照和正文解析，链接失效也能读；默认私密，没有社交推荐和算法推送；API/CLI 开放，能接自动化。

代价也摆在那：免费版 200 篇、每篇 3 个标注；AI 按积分算，Pro+AI 每月 2000 积分（E-315）。

### 4.2 实测结果

| 编号 | 实测任务 | 记录项 | 结果（2026-11-08 下午，手机 + 电脑 Web 为主） |
| --- | --- | --- | --- |
| C-1 | 微信内转发收藏一篇文章 | 步数、是否需跳转 App、失败提示 | **2 步，无需跳出微信**：绑定“Cubox 收藏助手”后，文章右上角 `···` → `转发给朋友` → 选收藏助手，自动抓取并云端存档。转发后可在对话框回复 `#标签` 或 `@@文件夹` 即时分类；也支持聊天记录、图片、语音（自动转文字） |
| C-2 | 浏览器扩展收藏并高亮 | 步数、是否自动收藏、标注是否同步 | PC 端浏览器插件可对普通公开网页划词高亮并自动收藏；再次访问该网页时插件可还原高亮（官方称“网页高亮”） |
| C-3 | 高亮 + 写想法 | 是否区分原文与想法、是否支持多色 | 支持多彩高亮与笔记；高亮/批注需在 Cubox 客户端、网页端或助手返回的阅读链接中完成（微信内不直接标注） |
| C-4 | 从标注跳回原文位置 | 跳转精度、链接失效时的快照兜底 | **跳回 Cubox 内部：句子级精准定位**（从标注卡片或导出的 Obsidian/Notion 笔记点击专属链接，唤醒 Cubox 并滚动到该句）。**跳回微信原网页：仅页面顶部**（微信网页无外部锚点接口，无法还原高亮）。快照可兜底原文被删 |
| C-5 | 同步到 Obsidian/Notion | 字段完整性、延迟、是否含原文链接 | 已实测（需 Pro）。Obsidian：官方插件 + API Key 本地拉取，可设 30/60 分钟轮询或手动秒级；字段含标题、正文（可选）、高亮、个人批注、高亮图片、标签、文件夹、创建时间、描述；双链接 `{{url}}` / `{{cubox_url}}`，Mustache 可 100% 自定义。Notion：官方授权绑定 Collections/Annotations 数据库，云端队列 1-5 分钟；字段含标题、类型、文件夹、标签、星标、创建时间、高亮、批注、所属文章；双链接；结构由官方固定 |
| C-6 | 免费额度边界 | 第 201 篇、每篇第 4 个标注的拦截提示 | 免费 200 篇、每篇 3 个标注；免费版不支持微信转发收藏、网页快照、嵌套文件夹、自动化同步导出；14 天 Pro+AI 试用 |
| C-7 | 分享一条标注给朋友 | 对方是否需注册、是否保留来源 | “分享阅读”生成含高亮/批注的公开快照网页，接收方无需注册即可阅读；页面为静态展示，无评论/留言/点赞组件 |
| C-8 | 检查是否存在讨论/社区 | 公开评论区、关注、动态 | **无**。官方明确“无社交推荐、算法推送”，数据默认私密；只有静态分享页 |
| C-9 | AI 问答与关联 | 中文问答、跨文章关联 | Pro+AI 提供 AI 解读、问答、语音朗读；跨文章关联与定时报告可用 |

> **同步避坑（实测）**：Obsidian 插件是单向增量同步，靠 Frontmatter 里的 `id` 识别。文章已同步后又追加高亮，可能覆盖或割裂；建议开启“仅同步已读/仅同步星标”，标注完成后再统一拉取。Cubox 另有官方 Readwise 同步接口，可把微信文章的高亮推送到 Readwise 再统一导出。

## 6. 实际用下来，强在哪、卡在哪

### 强的地方

- 微信入口最顺。绑定收藏助手之后，两步就能把公众号文章存进去，人不用离开微信（E-314）。这一点海外工具学不来。
- 来源保得住。正文解析加网页快照，原文被删了还能读（E-314）。
- 检索层次完整。全文、语义、自然语言问答都有，找旧文章不只靠关键词（E-314）。
- 数据能带走。同步、API、CLI、导出都有，用户不用担心被锁死（E-314、E-315）。
- 隐私定位清楚。默认私密、没有社交推荐，正好吸引不想公开的人（E-314）。

### 卡住的地方

- 明确不做讨论。官方把“无社交推荐、默认私密”当卖点，实测也只有静态分享页，没有评论、留言或关注（C-7、C-8）。这留下“公开讨论”的空位，也说明用户不愿在阅读工具里社交。
- 内容偏图文。播客和音频不是主线，官方功能表里没有音频转录，和“播客 + 书 + 文章”的统一出处差一截（C-9）。
- 跳回是“内准外不准”。跳回 Cubox 内部能到句子，跳回微信原网页只能到页面顶部，因为微信网页不给外部锚点接口（C-4）。想在微信场景“回到原句”，做不到。
- 免费额度低。200 篇、每篇 3 个标注，微信转发收藏、快照、嵌套文件夹、自动同步都在 Pro 之后（C-6）。
- AI 按积分。Pro+AI 每月 2000 积分，重度用会不够（E-315）。
- 同步有覆盖风险。Obsidian 是单向增量同步，靠 `id` 识别，文章同步后又追加高亮，可能覆盖或割裂（C-5 备注）。

### 对我们意味着什么

- “收藏 + 标注 + 回顾”在中文环境已经做得很完整，不能再当差异点。
- Cubox 的“默认私密”说明阅读工具里的用户不愿被公开打扰。我们要做讨论，就得把讨论绑在具体内容上，让用户自己选是否公开，而不是做成关系流。
- 快照这个思路值得借。出处不能只是一条链接，最好留一份可回溯的副本，否则链接失效，“来源上下文”就是空的。
