# 小宇宙用户旅程与关键流程体验记录

M2 在寝室收听音乐播客时，想记下对一首歌的感受，稍后回来重听。一个小时后，M2 从「我的评论」找回了当时写下的想法及其对应秒数，仍能解释原意。这次旅程中，带时间点的公开评论同时承担了交流和个人回顾的作用。对于只想把感受留给自己的听众，M2 在所测入口里没有找到私密记录选项。

## 2. 用户旅程

| 阶段 | M2 当时的目标 | 实际经过 |
| --- | --- | --- |
| 发现与选择 | 找一期感兴趣的音乐节目 | 浏览发现页后转向搜索，用“音乐”找到介绍王菲的单集并开始收听。 |
| 持续收听 | 关注节目，退出后接着听 | 订阅后可以在「订阅」查看近期更新；暂停退出后，再次打开时从底部播放器续播。 |
| 定位与表达 | 重听提到的片段，留下当时的感受 | 点击评论时间戳，音频跳到对应位置，评论页面仍然保留。M2 通过公开评论把自己的感受与时间点关联。 |
| 分享与回顾 | 把这段内容分享出去，稍后自己也能找到 | 分享图带有观点和二维码；一小时后，M2 从「我的评论」找回观点及秒数。 |

## 3. 关键流程实测

| 任务 | 动作或入口 | 实测结果与边界 |
| --- | --- | --- |
| X01 发现与搜索 | 浏览发现页 → 搜索“音乐” → 点开介绍王菲的单集 | 本次浏览未遇到感兴趣的内容。王菲这一具体主题促成了此次收听。 |
| X02 订阅与更新 | 在节目上点击订阅 → 到「订阅」查找 | 能从订阅入口再次进入，并看到近期更新。订阅时出现设置更新提醒的提示，提醒是否实际送达未记录。 [已订阅及优先通知提示](evidence/m2/E-212-X02-123103.jpg) [订阅更新列表](evidence/m2/E-212-X02-130929.jpg) |
| X03 暂停与续播 | 在 06:38 暂停 → 退出小宇宙 → 再打开 → 从底部播放器续播 | 预期位置与实际位置均为 06:38。这里测的是播放进度恢复；表中 06:35 是想记录歌曲感受的位置。 |
| X04 从评论跳回音频 | 在评论页点击一条评论中的时间戳 | 一次点击后音频跳至对应位置，界面停留在评论页。原表未填该条评论的具体秒数。 |
| X05 写下个人理解 | 在评论区给对应时间点留下观点 | 观点公开可见。在本次账号和操作路径中，M2 没找到把同一条带时间点的想法仅存为私人记录的选项。 [时点列表中的「06:35 好听」](evidence/m2/E-212-X05-123219.jpg) |
| X06 查看评论与回复 | 查看本集的讨论及回复 | 工作簿「证据与复核」确认看到了单集评论、楼中楼和主播回复。未记录具体对话、主播标识或回复媒介。 [补充样本：听众留言、麦克风标识和嵌套回复](evidence/m2/E-212-X06-133013.jpg)（图中未显示单集名，作为互动形式旁证） |
| X07 对外分享 | 生成带观点和二维码的分享图，查看外部打开结果 | 据 M2 记录，外部打开时保留节目、时间戳和观点，没有进入 App 内部。外部载体及能否从该秒直接播放未记录。 [分享图预览：06:35 评论、单集名和二维码](evidence/m2/E-212-X07-132532.jpg) |
| X08 找回个人记录 | 打开「我的评论」 | 找到的是自己的观点和对应秒数。历史记录、收藏两个入口的找回效果尚无实测结果。 |
| X09 稍后回顾 | 间隔约一小时 → 从「我的评论」找回 | M2 仍能解释当时的原意。此次记录覆盖短时回顾，未记录是否再次完整播放该片段。 |

## 4. 与组内记录的对照及评估

| 主题 | 可以引用的判断 | 依据 |
| --- | --- | --- |
| 时间点与讨论 | M3 在 3.4.4 记录了点击时间戳一步跳回。M2 在 3.4.2 同样观察到一步跳转，并补充了页面状态：音频移动，评论仍可阅读。 | X04；[M3 对照矩阵](content-capture-matrix.md) |
| 渠道通路（CH） | 本次搜索帮助新用户找到第一集想听的内容；订阅又提供了查看后续更新的入口。两个入口分别服务于首次发现和再次访问。 | X01、X02 |
| 客户关系（CR） | 听众可以围绕具体时刻表达感受，查看他人和主播的回复；自己的评论还能从个人入口找回。M2 实际用这条路径完成了一次短时回顾。 | X04–X06、X08、X09 |
| 适用边界 | 对愿意公开表达的听众，本次测试走通了“记录感受—保留出处—找回原意”。对想私下记录的听众，是否能以相同粒度保存，仍需另查入口。 | X05、X08、X09；原表「研究卡摘要」 |
