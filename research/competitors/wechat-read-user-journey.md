# 微信读书关键流程体验记录

M2 在寝室打开《百年孤独》，选取第一章首句做划线和批注。一小时后，M2 从「笔记」找到自己的想法，仍能回想起当时的意思。这次体验有两个不同的找回目标：从书架打开书，可以接着上次的进度读；从个人笔记打开批注，可以回到写下想法的那一段，同时看到原文和上下文。

## 1. 实测范围

| 项目 | 本次记录 |
| --- | --- |
| 体验人、日期与环境 | M2，2026-11-11，寝室；安卓手机，微信读书 10.2.2 |
| 账号与权限 | 已登录的新用户，非会员。本次可阅读并批注开头部分；据体验人记录，该账号需开通会员才能读完全书。 |
| 书籍与样本 | 加西亚·马尔克斯《百年孤独》第一章首句，以“多年以后，面对行刑队”开头。 |
| 阅读目的 | 因听说过这本书而随手翻阅。划线、批注和一小时后回顾是本次体验安排的任务。 |
| 证据来源 | M2 填写的《微信读书关键流程体验记录.xlsx》，下表沿用原始任务号 W01–W10。后补 4 张图片，见对应步骤（E-213）。 |

## 2. 关键流程与实测结果

| 任务 | 实际操作 | 观察结果 |
| --- | --- | --- |
| W01 搜索与选书 | 搜索“百年孤独”，从结果打开书籍。 | 已知书名是这次选书的线索。M2 另记录，进入书后还可用全书搜索按关键词查找内容。 [书籍详情：该账号首月特惠 9 元/月及单书购买入口](evidence/m2/E-213-W01-140356.jpg) |
| W02 退出与续读 | 在第一章第二页退出微信读书，再打开。 | 回到了离开时的第一章第二页。 |
| W03 划线 | 长按首句，拖动选区边界，保存目标文字。 | 成功保留选中的原文和书名；此次查看划线记录时未看到对应章节名称。 |
| W04 写想法 | 在阅读页长按选中文字，在该处写下想法。 | 想法与所选文字关联。M2 记录保存前后均可辨认可见范围，笔记可以设为私密；原表未注明这条笔记最终选择的范围。 |
| W05 查看书中讨论 | 点击目标原句，查看其他读者留下的笔记。 | 从这条入口看到的讨论对应同一句文字。M2 还在复核表中记录了全书、章节和段落三个层级的书友互动。 |
| W06 查看书友互动 | 查看他人评论及回复入口。 | 可见点赞、回复操作，M2 记录从回复可以找回讨论上下文。原表未注明是否实际点赞或发送回复。 |
| W07 从书架找回 | 退出阅读界面，从书架再次点开《百年孤独》。 | 落点是上次阅读进度。本项实际使用的入口为「书架」。 |
| W08 从个人笔记找回 | 从个人笔记返回对应批注。 | 落点是写批注的段落。原文有黄色高亮，能同时看到前后文和自己的理解。 [笔记列表：书名、个人想法与所引原句](evidence/m2/E-213-W08-141315.jpg)（回到高亮段落的操作见文字记录） |
| W09 分享 | 比较图片与链接两种分享形式。 | 据 M2 记录，图片带有想法、原文和书名，无法从图上直接跳转到书籍；链接可跳转至对应想法或段落。接收端设备和账号条件未记录。 [纯摘录分享图](evidence/m2/E-213-W09-14992.jpeg) [带个人想法的摘录分享图](evidence/m2/E-213-W09-15034.jpeg)（与 W08 笔记措辞不同，仅核对分享格式） |
| W10 稍后回顾 | 间隔约一小时，进入「笔记」找到此前的想法。 | M2 能回想起当时的意思。本次记录覆盖短时回顾。 |

## 3. 体验判断及与小宇宙的对照

| 主题 | 本次体验支持的判断 | 依据 |
| --- | --- | --- |
| 来源与定位 | 微信读书的划线记录可辨认书名，从笔记跳回时又能看到高亮原文和前后文。整理引用时，章节名称仍需回到书中核对。小宇宙对应的定位线索是音频时间戳，点击后能在继续看评论的同时听到该处。 | W03、W08；X04 |
| 个人想法与公开讨论 | 微信读书允许给选中文字写私密笔记，也可从原句查看书友想法。小宇宙实测中，M2 通过公开的时间点评论留下个人感受，在所测入口中未找到仅自己可见的选项。 | W04–W06；X05、X06 |
| 回顾与分享 | 两次体验都在一小时后找回了自己的表达。微信读书从「笔记」回到目标段落，小宇宙从「我的评论」找到观点及对应秒数。若希望分享对象直接定位书中段落，本次微信读书记录支持选用链接；图片适合展示书名、原文和想法。 | W08–W10；X07–X09 |

对照材料见[小宇宙用户旅程与关键流程体验记录](xiaoyuzhou-user-journey.md)。上述结论限于本次单一账号、书籍可读部分和一小时回顾，付费后的阅读体验及长期复用效果仍待验证。
