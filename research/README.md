## 使用说明

- 归档文件反映的是 2026-11-07 前后的研究状态，不保证其中涉及的产品功能、价格、用户规模和市场数字在之后仍然有效。
- 深度研究报告中的 `cite...` 是原研究环境中的临时引用标记，不是可直接用于 GitHub 或课程论文的稳定参考文献。正式报告使用前，必须找到对应原始来源并补齐标题、发布机构、日期和可访问 URL。
- 选题报告中对方向 A 的判断是项目决策依据，不代表需求假设已通过用户访谈验证。
- 新证据若与历史报告冲突，应保留历史版本并在当前研究文档和决策日志中记录修正，不应悄悄覆盖。
