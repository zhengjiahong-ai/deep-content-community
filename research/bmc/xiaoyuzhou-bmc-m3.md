## 4. 三个模块如何互相支撑

```
创作者（KP-1）
   │ 供给内容（RSS / 原生托管）
   ▼
核心资源 KR-1 内容供给 ──► 关键业务 KA-1 发现/KA-2 分发 ──► 听众（CS）
   ▲                              │
   │                              ├─► KA-3 互动 ──► 社区氛围（KR-3）
   │                              │
   └── KA-4 创作者后台 ◄──────────┘
                                   │
品牌（KP-2）──► KA-5 商业化 ──► 收入（R$）──► 按平台规则分成回创作者
Apple（KP-4）──► 渠道扣费 ──► 成本（C$）
监管（KP-5）──► KA-6 治理 ──► 合规成本（C$）
```

- 资源怎么撑业务：KR-1 决定 KA-1/KA-2 的供给规模；KR-3 决定 KA-3 的社区质量；KR-4/KR-5 决定 KA-4 的后台体验。
- 业务怎么反哺资源：KA-3 的互动攒成 KR-3 的社区氛围；KA-4 的服务和数据攒成 KR-6 的创作者关系。
- 合作怎么接进来：KP-1 供给 KR-1；KP-2 支撑 KA-5；KP-4 直接进 C$；KP-5 约束 KA-6。
- 对外部模块：KR-1/KR-3 支撑 M1 的价值主张；KA-1/KA-2 对应 M2 的渠道通路；KA-5 与 KP-2/KP-4 对应 M4 的收入和成本。

## 5. 实测补充：主播后台与商业化动作

### 5.1 后台功能菜单

| 模块 | 可见能力 |
| --- | --- |
| 节目管理 | 上传音频创建单集（原生托管）；RSS 链接认领；定时发布；节目封面/简介；多运营者与认证主播 |
| 内容工具 | 时间点标记（结构化 Show Notes）；单集投票；节目公告（每月 2 次）；100 小时收听祝贺语；评论管理与黑名单禁言 |
| 私域 | 节目专属联系方式（公众号/微信号/小红书/微博）；播客名片 |
| 数据 | 全局与单集看板；Excel 报表导出 |
| 收益 | 付费内容配置；赞赏开关；收益钱包；追光商单入口 |

### 5.2 数据维度

- **节目全局**：总订阅数、每日新增/取关趋势、总播放量、总收听时长、听众画像（性别、年龄段、地域、收听时段）、忠实听众列表。
- **单集**：播放量、完播率、收听留存衰减曲线、高能点赞分布、评论数、分享数、收藏数、赞赏明细。

### 5.3 商业化动作（价格与分成归 M4）

后台能看到四类动作：赞赏开关、付费内容配置（单集/专题/节目）、收益钱包、追光商单入口。结算走实名认证、银行卡或支付宝，平台代扣个税。

具体定价、分成比例、渠道抽成属于收入与成本模块，由 M4 统一核算；我只把动作和入口记在这里，避免和 M4 的口径打架。
