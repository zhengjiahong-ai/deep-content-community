## 1. 项目简介

本项目面向有深度内容消费习惯的用户，探索一个位于播客、书籍、文章等内容平台之上的“内容后思考层”。

当用户在一段播客、一篇文章或一本书中遇到值得记住、回应或继续思考的观点时，项目希望帮助其把瞬时的思想共鸣转化为可保存、可讨论、可连接、可回顾的个人思想资产。

**核心产品命题：**

> 面向深度播客与阅读用户，把“听到/读到一个有共鸣的观点”转化为“可保存、可讨论、可连接、可回看的个人思想资产”。

## 2. 本轮课程作业的冻结决策

## 5. 竞品研究边界

小宇宙是核心竞品，重点体验：
- 播客内容发现、订阅与收听；
- 单集和时间点互动、评论与讨论；
- 听众、创作者与平台关系；
- 收藏、回访等用户管理功能；
- 可见的付费内容、会员、广告或其他商业化入口。

Snipd、Readwise、flomo、豆瓣仅作为辅助对照。不得把它们全部视为同一种直接竞品。

## 6. 研究原则

- 区分事实、推断和假设；
- 重要结论使用可追溯来源，正文标记并用脚注记录；
- 关键数字必须注明时间、范围和统计口径；
- 未公开的财务数据不得编造；
- 保留反向证据和研究局限；
- 使用团队自己的语言，不大段复制，不让 AI 替代团队判断。
