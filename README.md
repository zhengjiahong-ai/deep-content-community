# 深度内容思考与共鸣社区

> 项目仓库：zhengjiahong-ai/deep-content-community  
> 项目类型：课程需求分析与竞品生态/商业模式研究  
> 项目负责人：M1  
> 官方截止：2026-11-30 20:00（北京时间）

## 1. 项目简介

本项目定位为**深度内容思考与共鸣社区**，围绕播客、书籍和文章中的具体观点组织表达、上下文讨论、同好发现与个人沉淀。观点卡是讨论单元，讨论空间是基础产品形态，个人沉淀承接持续价值。

核心命题（待验证）：

> 帮助用户围绕跨来源深度内容观点建立共鸣与讨论空间，让片段及其出处成为交流上下文，让个人表达、他人回应和后续思考能够持续沉淀。

## 2. 已确认的课程研究决策

- 选题：深度内容思考与共鸣社区；
- 课程焦点竞品：小宇宙；
- 小宇宙研究范围：播客内容、互动与社区；
- 竞品研究方式：从单一产品扩展为竞品生态图谱；
- SWOT 深入方向：价值主张；
- 蓝海战略方向：价值主张；
- 新价值初步方向：以跨来源观点为组织单元的共鸣社区；观点卡承载上下文，讨论空间构成基础体验，个人沉淀形成连续价值。

## 3. 竞品生态

研究十个代表产品：
- 内容平台：小宇宙、喜马拉雅、微信读书；
- 内容捕捉：Snipd、Readwise Reader、Cubox；
- 个人知识：flomo、Obsidian；
- 内容社区：豆瓣、即刻。

小宇宙完成课程要求的完整 BMC；其他产品用于同维度比较、商业模式快照和价值主张研究，不把所有产品都直接认定为竞品。
