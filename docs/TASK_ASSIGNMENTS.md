## 一、项目目标

围绕“深度内容思考与共鸣社区”，研究用户如何在播客、书籍和文章中捕捉有价值的观点、保留来源上下文、形成个人思考、与他人交流并在未来重新使用。

本轮不是简单做一个小宇宙产品介绍，而是要理解现有产品生态如何分工，以及本组设想在这张生态图中究竟有什么价值。

本轮最终提交一份整合 PDF，完成教师要求的：
1. 选题与价值创造；
2. 竞品选择；
3. 竞品完整商业模式画布；
4. 总体评估与 SWOT；
5. 商业模式外部环境；
6. 蓝海战略 ERRC 与新商业模式画布。

## 二、研究范围与竞品结构

### 2.1 课程焦点竞品

小宇宙仍然是课程焦点竞品，重点研究播客内容、互动与社区。对小宇宙绘制完整的九模块 BMC，并完成四部分总体评估及价值主张 SWOT。

### 2.2 竞品生态

不能只研究小宇宙。全组需覆盖以下十个代表产品：

| 类别 | 产品 | 研究重点 |
| --- | --- | --- |
| 内容平台 | 小宇宙 | 播客消费、时间点互动、评论社区、创作者关系 |
| 内容平台 | 喜马拉雅 | 综合音频内容、播客、创作者生态和商业化 |
| 内容平台 | 微信读书 | 书籍阅读、划线、想法、书中讨论 |
| 内容捕捉 | Snipd | 播客片段、转录、摘要、问答、分享与导出 |
| 内容捕捉 | Readwise Reader | 多来源阅读、标注、批注、同步和回顾 |
| 内容捕捉 | Cubox | 网页收藏、阅读、标注、搜索、回顾和分享 |
| 个人知识 | flomo | 快速记录、标签、相关笔记、回顾 |
| 个人知识 | Obsidian | 双向链接、反向链接、知识图谱 |
| 内容社区 | 豆瓣 | 书影音条目、评论、小组、同好发现 |
| 内容社区 | 即刻 | 兴趣圈子、动态表达、评论与同好连接 |

产品分为两层研究深度：
- **深度研究：**小宇宙、微信读书、Snipd、Readwise Reader、Cubox、flomo、豆瓣。
- **补充扫描：**喜马拉雅、Obsidian、即刻。

“深度研究”不是要求写七份完整 BMC，而是按统一维度比较用户任务、价值主张、关键流程、商业模式特征和局限。小宇宙是本轮唯一必须完成完整九模块 BMC 的课程焦点竞品。

### 2.3 竞争关系不能预先定性

十个产品不全部是直接竞品。最终应结合用户任务判断直接竞争、间接竞争、替代方案或能力参照。尤其需要研究用户把多个工具组合使用的情形。

## 三、四人职责

### M1：项目负责人、用户研究综合、价值主张与蓝海战略

**研究职责**
1. 整理第一阶段 8 份真实访谈，提取用户实际行为、工具链、痛点、替代方案、采用阻力和反例。
2. 单独整理 16 份 AI 模拟材料，仅用于补充问题探索，不得与真实访谈混合统计。
3. 形成“用户任务链”：内容消费 → 捕捉片段 → 保留来源 → 写下个人理解 → 分享/讨论 → 跨内容关联 → 回顾复用。
4. 负责小宇宙 BMC 的价值主张模块，分别分析听众、创作者及其他有证据支持的参与方。
5. 结合全组竞品研究，比较不同产品的价值主张和能力边界，识别已经被满足的需求与可能的空缺。
6. 负责价值主张深入 SWOT。
7. 负责价值主张方向的 ERRC 和新 BMC 总体设计。
8. 负责宏观经济影响 4 个子方向。
9. 负责报告整合、最终逻辑审查和提交。

**交付物**
- 用户研究综合报告；
- 用户任务链和现有工具组合分析；
- 小宇宙价值主张模块；
- 价值主张 SWOT 图及证据矩阵；
- 宏观经济影响 4 项分析；
- ERRC 四项行动；
- 新商业模式画布；
- 最终整合报告。

**关键问题**
- 用户遇到的到底是观点容易遗忘、原始来源难找、观点无法组织，还是讨论结果无法沉淀？
- 哪些需求在真实访谈中出现，哪些仅出现在 AI 模拟或概念反馈中？
- 现有工具组合是否已经解决问题？用户为什么仍会切换工具？
- 新产品创造的价值是否足以抵消额外安装、学习、迁移和社交成本？

### M2：内容消费平台、用户界面与市场影响力

**产品研究分工**
- 深度研究：小宇宙、微信读书；
- 补充扫描：喜马拉雅。

**研究职责**
1. 研究小宇宙的节目发现、搜索、订阅、播放、时间点互动、评论、回复、收藏、历史记录和创作者互动。
2. 研究微信读书的书籍发现、阅读、划线、想法、书中讨论、书友互动和阅读记录。
3. 扫描喜马拉雅的播客入口、内容生态、创作者关系和商业化方式。
4. 对比音频内容与书籍阅读场景中，内容发现、消费、互动和观点记录的差异。
5. 负责小宇宙 BMC 的客户细分、渠道通路和客户关系。
6. 负责总体评估中的用户界面部分，列出有证据的加分项与减分项。
7. 负责市场影响力 5 个子方向。
8. 为 M1 的价值主张 SWOT 和 ERRC 提供用户侧与内容平台侧证据。

**交付物**
- 内容平台竞品对比；
- 小宇宙用户旅程和关键流程体验记录；
- 微信读书关键流程体验记录；
- 喜马拉雅补充扫描；
- 小宇宙 BMC：客户细分、渠道通路、客户关系；
- 用户界面总体评估；
- 市场影响力 5 项分析。

**关键问题**
- 内容平台如何获取和留住用户？
- 用户消费内容时是否能够自然地保存观点？
- 讨论是否依附于单集或单本书？
- 个人观点、他人观点与原文上下文之间如何关联？
- 用户在平台内完成任务后，哪些内容仍会流向外部工具？

## 四、小宇宙完整 BMC 的模块责任

| BMC 模块 | 负责人 | 必须分析的内容 |
| --- | --- | --- |
| 客户细分 | M2 | 听众、创作者及其他已确认参与方；使用者与付费者区别 |
| 价值主张 | M1 | 各参与方获得的核心价值及证据 |
| 渠道通路 | M2 | 发现、获取、使用、分发和创作者触达渠道 |
| 客户关系 | M2 | 用户留存、互动、社区、创作者关系 |
| 核心资源 | M3 | 内容供给、品牌、用户网络、技术、数据、团队等 |
| 关键业务 | M3 | 内容发现、分发、播放、互动、运营和治理等 |
| 重要合作 | M3 | 创作者、内容机构、技术/分发渠道及其他可确认合作 |
| 收入来源 | M4 | 已确认的会员、付费内容、广告、赞助等；未确认项不得写成事实 |
| 成本结构 | M4 | 内容、技术、带宽、研发、运营、审核、获客等成本驱动因素 |

每个模块都必须说明事实来源、价值流动和与其他模块的关系。不能只堆砌功能词。

价值主张 SWOT 的画布标注要求：

- O/T 应为外部环境因素，不得把内部产品缺陷误列为威胁；
- SWOT 既要考虑小宇宙，也要结合其他竞品的能力和行业变化。

## 八、蓝海战略与新 BMC

方向已确定为价值主张。M1 负责整合，其他成员提供对应模块输入。

- M1：结合真实用户证据、竞品价值主张和 SWOT，形成 ERRC 主线。
- M2：分析新方案对客户细分、渠道通路和客户关系的影响。
- M3：分析新方案对核心资源、关键业务和重要合作的影响。
- M4：分析新方案对收入来源、成本结构和可持续性的影响。

ERRC 必须说明：
- 删除：哪些现有价值要素或行业惯例不再提供；
- 消减：哪些要素应低于行业常见水平；
- 提升：哪些要素应高于行业常见水平；
- 创造：哪些新价值要素需要建立。

四项行动必须形成有取舍的价值主张，不得把“增加更多功能”当作蓝海战略。

新 BMC 九个模块需由对应负责人提供变化建议，M1 统一整合。

教师原文提及“课程作业 1 和 2 的商业模式画布”。如课程上下文不能明确该指代，M1 应向教师确认；不能擅自缩减教师要求。

## 九、研究证据与写作规范

所有成员统一执行：
1. 区分 FACT、INFERENCE、HYPOTHESIS。
2. 产品功能优先使用官方页面、帮助中心、应用商店说明和实际体验。
3. 市场数据优先使用原始报告、公开数据和可靠新闻。
4. 每条关键数据记录发布时间、统计口径、地区、样本和访问日期。
5. 企业宣传不能单独证明产品效果或用户满意度。
6. 未公开的收入、成本、用户数、付费率等明确标注，不得编造。
7. 不将“没有搜到”写成“产品没有该功能”。
8. 不将 AI 模拟访谈当成真实用户证据。
9. 保留反向证据和产品局限。
10. 正文重要结论处标记引用，参考文献中保留可追溯来源。
11. 最终报告使用团队自己的语言，不大段复制网页或 AI 输出。

## 十、协作方式（不设置内部硬截止）

团队不设置人为的内部日期和硬截止。按以下工作阶段推进：

1. **研究口径对齐：**全体阅读本任务书、课程原文和证据规范，确认产品分工。
2. **独立产品研究：**各成员按分工完成产品体验、来源收集和研究记录。
3. **跨产品比较：**将不同产品放入统一矩阵，识别能力重叠、差异和替代路径。
4. **小宇宙 BMC 与总体评估：**由模块负责人提交，M1 统一检查。
5. **外部环境研究：**四位成员完成各自负责的教材子方向。
6. **SWOT 与蓝海战略：**M1 根据团队证据整合，其他成员提供模块变化建议。
7. **报告整合与审核：**先检查内容完整和论证，再统一文风、脚注和图表。
8. **最终提交：**M1 在官方截止前提交整合 PDF。

## 十一、交叉审阅

- M2 复核 M3 的内容捕捉工具研究和基础设施判断；
- M3 复核 M4 的知识管理/社区研究和财务判断；
- M4 复核 M2 的内容平台研究和用户界面判断；

交叉审阅的目标是找事实错误、证据缺口、逻辑跳跃和竞品能力误判，不是为了统一个人表达风格。
