## 1. 选题与价值创造

### 1.3 我们希望创造的价值

说明内容片段、个人思考和交流之间的关系。不要把未验证的功能写成已经成立的市场需求。

## 2. 核心竞品选择与研究范围

### 2.1 为什么选择小宇宙

- 内容发现、订阅和收听；
- 单集评论、时间点互动和讨论；

- 收藏、回访及可见商业化入口。

说明辅助竞品 Snipd、Readwise、flomo、豆瓣仅用于特定用户任务对照，不替代核心竞品。
