## DEC-001：确定课程项目方向

- **日期：**2026-11-07
- **状态：**已确认
- **决策：**选择方向 A——播客 / 深度阅读思想共鸣社区，并正式收窄定位为“深度内容思考与共读平台”。
- **团队背景：**四人团队最终支持方向 A。
- **比较结果：**

| 排名 | 候选方向 | 综合得分 | 决策位置 |
| --- | --- | ---: | --- |
| 1 | A：播客 / 深度阅读思想共鸣社区 | 82.5/100 | 已选择 |
| 2 | D：家庭维修透明报价与履约管理平台 | 80.0/100 | 第二选择 |
| 3 | C：家庭数字记忆档案 | 76.0/100 | 未选择 |
| 4 | B：情绪化专注工具 | 72.5/100 | 未选择 |

- **评分说明：**评分用于课程项目方向的结构化比较，不是统计意义上的测量结果。A 与 D 仅相差 2.5 分，不应描述为压倒性胜出。
- **选择理由：**
  1. 目标用户可从大学生、研究生和年轻知识工作者中接触，四人团队能够开展一手研究；
  2. 小宇宙是可直接体验、资料相对丰富的核心竞品；
  3. 项目有机会研究内容消费、个人知识沉淀和小规模讨论之间的连接问题；
  4. 相比家庭维修平台，不依赖维修师傅、平台商户和线下履约资源，执行成本更可控。
- **主要保留意见：**
  1. 用户是否真的存在高频的“观点未能沉淀”问题，仍需访谈；
  2. 小宇宙已有时间点评论和互动，不能把“没有讨论”当作痛点；
  3. Snipd、Readwise 等已有部分摘录与知识沉淀能力，差异化必须通过真实流程对比；
  4. 用户是否愿意额外使用一个应用，以及是否愿意付费，尚未验证。
- **影响：**项目问题域与核心竞品冻结；后续允许在证据支持下调整目标用户细分、核心场景和 MVP，不随意更换课程选题。

## DEC-002：确定核心竞品与辅助竞品

- **日期：**2026-11-07
- **状态：**已确认
- **决策：**小宇宙作为课程作业核心竞品；Snipd、Readwise、flomo 和豆瓣作为辅助竞品或机制参照。
- **理由：**小宇宙覆盖播客内容消费和讨论入口，适合完整分析其用户、内容、平台关系和商业模式；辅助产品分别提供内容摘录、知识回顾、个人记录和兴趣讨论的对照。
- **约束：**辅助产品不必然是直接竞品；所有功能、价格和商业模式细节仍需在实际体验及可靠来源中核验。

## DEC-003：采用“内容后思考层”定位

- **日期：**2026-11-07
- **状态：**已确认（初步定位）
- **决策：**产品不做新的播客播放器或泛社交社区，而定位为深度内容消费后的思考与共读层。
- **核心命题：**把“听到/读到一个有共鸣的观点”转化为“可保存、可讨论、可连接、可回看的个人思想资产”。
- **候选核心链路：**片段捕捉 → 个人思考 → 小组讨论 → 跨内容关联 → 回顾复用。
- **待验证：**链路中的哪些步骤真实存在、哪些步骤最重要、用户是否愿意持续完成。
