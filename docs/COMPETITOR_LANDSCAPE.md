# 竞品生态研究框架

> 版本：v2.0  
> 更新日期：2026-11-08  
> 课程焦点竞品：小宇宙  
> 研究原则：不把不同类型的产品混为一类，不把“有类似功能”直接等同于“完全相同的竞品”。

## 1. 为什么必须从单一产品扩展到竞品生态

本项目设想的用户任务跨越多个产品类别：用户可能在小宇宙听播客，在微信读书阅读，在浏览器或 Cubox 保存文章，用 Snipd 捕捉播客片段，再把想法写入 flomo 或 Obsidian，最后在豆瓣、即刻或微信群中讨论。

因此，用户真正的替代方案可能不是某一个 App，而是多个工具拼接起来的工作流。

如果只分析小宇宙，会遗漏：
- 播客片段捕捉和转录工具；
- 跨来源阅读与摘录管理工具；
- 个人知识记录和观点关联工具；
- 书籍原文讨论和兴趣社区；
- 用户用现有工具组合完成同一任务的方式。

所以，本组采用“竞品生态图谱 + 同维度对比 + 小宇宙完整 BMC”的研究结构。

## 3. 竞争关系判断

不要在研究开始前就把十个产品都称为直接竞品。应从用户任务判断：

- **直接竞争：**产品面向相似用户，在相似场景中争夺相同的主要任务和预算；
- **间接竞争：**只覆盖本项目工作流中的一部分，但能替代某个关键步骤；
- **替代方案：**用户通过多个工具、社交平台或线下方式拼接完成目标任务；
- **能力参照：**某个产品的特定机制值得研究，但其整体定位并不与本项目竞争。

最终分类由实际产品体验和用户访谈证据决定，而不是由产品名称或功能相似度决定。

## 4. 跨产品统一比较框架

每个产品均按以下维度填写：

| 比较维度 | 需要记录的内容 |
| --- | --- |
| 目标用户 | 主要使用者、内容提供者、可能的付费者 |
| 核心任务 | 用户为什么打开产品 |
| 内容类型 | 播客、书籍、文章、网页、音视频、用户生成内容 |
| 内容入口 | 平台内发现、订阅、外部导入、分享链接、文件上传 |
| 内容粒度 | 节目、单集、时间点、整篇文章、段落、书摘、卡片 |
| 来源上下文 | 是否保留标题、作者、原文、时间点、页码、跳转链接 |
| 捕捉成本 | 保存一个片段需要多少操作，能否在消费当下完成 |
| 个人表达 | 是否能将摘录与自己的想法、问题、评论区分开 |
| 跨源组织 | 能否统一管理不同平台、不同类型的内容 |
| 观点关联 | 标签、双向链接、相关笔记、图谱或语义关联 |
| 讨论机制 | 公开评论、时间点评论、原文批注、回复、私密小组 |
| 社区发现 | 能否发现同好、主题、创作者或高质量讨论 |
| 回顾检索 | 搜索、筛选、提醒、每日回顾、历史记录 |
| 分享导出 | 是否保留原文来源和上下文，是否可导出到其他工具 |
| 商业模式 | 免费/订阅/广告/内容付费/其他已确认模式 |
| 关键成本与资源 | 内容、技术、云服务、AI、版权、创作者、运营、治理 |
| 关键限制 | 版权、隐私、平台封闭、导入成本、社区治理、迁移成本 |

所有功能状态用以下标签，不允许仅凭印象填“有/没有”：
- 已实测；
- 官方资料确认；
- 第三方资料提及；
- 尚未核实；
- 不适用。

## 5. 深度研究产品的具体问题

### 5.1 小宇宙

1. 新用户如何发现和选择节目？
2. 订阅、播放列表、历史记录和收藏如何工作？
3. 时间点评论、点赞、高能片段和单集评论之间是什么关系？
4. 用户如何回复、点赞和继续讨论？
5. 创作者如何与听众互动？
6. 用户如何从评论回到音频具体位置？
7. 公开讨论如何形成平台社区氛围？
8. 平台如何支持创作者成长和内容供给？
9. 公开可见的商业化入口有哪些？
10. 用户的观点是否可以跨单集、跨节目、跨内容类型沉淀？
11. 当前产品是否已经覆盖本项目设想中的某些步骤？

### 5.2 微信读书

1. 书籍发现、阅读和付费内容如何组织？
2. 划线、写想法、书中观点和评论之间如何关联？
3. 用户能否看到他人的观点并参与讨论？
4. 个人阅读记录、书架和笔记如何回顾？
5. 内容讨论是否依赖具体书籍及原文上下文？
6. 用户能否把书中观点迁移到其他来源的知识库？

### 5.3 Snipd

1. 如何在听播客时低摩擦捕捉片段？
2. 保存结果包含音频、转录、摘要和来源哪些信息？
3. AI 自动摘要、章节、问答和自定义提示如何工作？
4. 用户如何管理和搜索保存的 snips？
5. 如何分享、导出或同步到 Notion、Readwise、Obsidian 等工具？
6. 它的产品价值是听播客、学习、知识捕捉还是 AI 内容处理？
7. 其订阅和 AI 使用限制如何影响成本与用户采用？

### 5.4 Readwise Reader

1. 如何汇集文章、通讯、PDF、EPUB、视频等不同来源？
2. 高亮和批注如何保存并同步到 Highlights？
3. 用户如何搜索、过滤和回顾摘录？
4. 分享带注释的文档如何工作？
5. Ghostreader 等 AI 功能如何参与阅读？
6. 它与播客原始时间点、音频上下文之间的关系如何？

### 5.5 Cubox

1. 如何从网页、微信或其他应用收藏内容？
2. 高亮、笔记和原文跳转如何关联？
3. 如何通过全文/语义搜索和回顾找回旧内容？
4. 如何分享收藏、标注和观点？
5. 如何与 Obsidian、Notion 等知识工具同步？
6. 其官方产品方向是否正在从广义信息管理收敛到阅读记忆？
7. 它的私密空间与本项目小范围讨论设想之间有什么差异？

### 5.6 flomo

1. 快速记录的入口和操作成本如何？
2. 标签、多级标签、相关笔记和反向链接如何组织想法？
3. 每日回顾、随机漫步和认知地图如何帮助再发现？
4. 内容是否默认私密？分享和协作的边界是什么？
5. 用户如何从外部内容导入记录？
6. 它与本项目的区别是来源上下文、讨论场景还是内容发现？

### 5.7 豆瓣

1. 书影音条目如何成为内容讨论入口？
2. 评分、短评、长评和小组讨论之间如何组织？
3. 用户如何发现同好和主题？
4. 社区规则、管理员和平台治理如何分工？
5. 讨论是否围绕原文的具体片段，还是围绕整个作品和主题？
6. 内容评价、兴趣社群与个人知识沉淀之间有哪些断点？

## 6. 补充扫描产品

### 喜马拉雅
观察综合音频内容、播客入口、创作者激励、会员/广告/付费内容和多终端场景。

### Obsidian
观察本地知识库、双向链接、反向链接和图谱视图，重点判断知识关联机制的可迁移性和学习成本。

### 即刻
观察兴趣圈子、动态表达、评论互动、推荐和同好连接，重点判断其讨论场景是否与具体内容来源绑定。

## 7. 商业模式比较层次

### 第一层：完整 BMC

小宇宙必须完成九个模块的完整商业模式画布。

### 第二层：竞品商业模式快照

其他代表产品至少记录：
- 客户群体；
- 核心价值主张；
- 主要渠道与客户关系；
- 可核实的收入模式；
- 关键资源、活动和合作；
- 主要成本或成本驱动因素；
- 未公开信息与推断边界。

### 第三层：价值主张对比

将不同产品放在用户任务链中比较，而不是只比较功能数量。

## 9. 研究结论必须回答的问题

1. 哪些用户任务已被现有产品很好地满足？
2. 哪些能力已经成为行业常见能力，不应再被包装成创新？
3. 用户目前如何在多个产品之间迁移内容和观点？
4. 工作流中真正的断点在哪里：捕捉、来源保留、个人表达、跨源关联、讨论还是回顾？
5. 哪个断点有真实用户证据支持？
6. 新产品是否有必要独立存在，还是应当成为现有工具的插件、同步层或轻量协作空间？
7. 用户为什么不直接继续使用现有产品组合？
8. 新价值是否值得用户付出额外学习、迁移和社交成本？

研究目标不是证明本组的构想一定正确，而是找到最有证据支持的价值机会，并允许研究结果收缩或修正原始构想。
